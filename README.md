# RM: FB2Term Reader

## 1. Назначение проекта

**FB2Term Reader** — консольная читалка FB2-файлов под Linux с TUI-интерфейсом на Python + Textual.<img width="1308" height="624" alt="Screenshot 2026-05-21 at 16 13 21" src="https://github.com/user-attachments/assets/f212ccbf-cbbb-4dde-b9ac-b295fec79f49" />


Основная цель проекта — сделать удобную минималистичную читалку в терминале:

- чтение `.fb2` и `.fb2.zip`;
- просмотр библиотеки книг из заданной директории;
- удобная навигация по книге;
- сохранение позиции чтения;
- закладки;
- поиск;
- настройка режима отображения текста.

Приложение не должно пытаться заменить полноценные GUI-читалки. Его задача — быстрый, чистый, клавиатурно-ориентированный reader для терминала.

---

## 2. Целевая платформа

### 2.1. ОС

Основная платформа:

- Linux.

Допустимо:

- macOS как best-effort;
- Windows/WSL как best-effort.

### 2.2. Терминалы

Ожидаемые терминалы:

- GNOME Terminal;
- Konsole;
- Kitty;
- Alacritty;
- WezTerm;
- xterm-compatible terminals.

Приложение не управляет шрифтом терминала напрямую. Шрифт выбирается пользователем в настройках терминала.

## 3. Стек

### 3.1. Язык

- Python 3.12+

### 3.2. UI

- Textual

### 3.3. Парсинг FB2

На MVP допустим один из вариантов:

1. Использовать готовую библиотеку для FB2.
2. Реализовать собственный минимальный XML-парсер поверх `xml.etree.ElementTree`.
3. Позже заменить парсер на более строгий и устойчивый модуль.

Для MVP предпочтительно начать с собственного ограниченного парсера, если готовая библиотека создаёт проблемы с зависимостями или качеством извлечения текста.

### 3.4. Хранение состояния

MVP:

- JSON-файл в пользовательской директории.
